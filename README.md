# Метеостанция и контроллер автоматизации на ESP8266 (ESP-07)

Многофункциональная метеостанция с локальным управлением через дисплей LCD2004 и энкодер, веб-интерфейсом, REST API, приёмником радиодатчиков 433 МГц, управлением сервоприводом, системой бесперебойного питания (24 В + АКБ 18650) и программируемой автоматизацией реле.

## Основные возможности

* **Датчики:** до 12 шт. `DS18B20` (1-Wire), `DHT22/21`, I2C-устройства (`BME280`, `BMP180/085`, `BH1750`, `PCF8574`).
* **Радиоканал 433 МГц:** приём кодов от беспроводных датчиков через модуль `SRX887` (`RCSwitch`).
* **Управление реле (`HL-52S` через `PCF8574`):**
  * Побитовое ручное управление в меню на экране с настройкой инверсии (`IN/OUT`, активный `LOW/HIGH`).
  * Мгновенное переключение с главной веб-страницы.
  * До 8 правил автоматизации (`>`, `<`, `>=`, `<=`, `==`) по имени любого датчика (`DS_1`, `BME_1`, `BAT`, `RF`) с гистерезисом.
* **Локальный интерфейс:** дисплей `LCD2004` (I2C), часы `DS1307` с синхронизацией по `NTP`, индикация заряда АКБ 18650, наличия входных 24 В и статуса Wi-Fi.
* **Веб-интерфейс и API:** автообновляемая панель мониторинга, защищённые паролем настройки (`/settings`, `/rules`) и HTTP API (`/api/sensor?name=ИМЯ`, `/api/all`).

## Распиновка ESP-07

* **GPIO4 / GPIO5:** Шина I2C (`SDA` / `SCL`, подтяжка `4.7 кОм` к `+3.3 В`) -> датчики 3.3 В + конвертер уровней на LCD2004 и DS1307.
* **GPIO14:** Шина `1-Wire` (DS18B20, подтяжка `4.7 кОм` к `+3.3 В`).
* **GPIO12:** Датчик `DHT22` (подтяжка `4.7 кОм` к `+3.3 В`).
* **GPIO13:** Приёмник `SRX887` (через делитель `10 кОм / 20 кОм` для согласования 5 В -> 3.3 В).
* **GPIO16:** Сервопривод (через защитный резистор `330 Ом – 1 кОм`).
* **GPIO2 / GPIO15 / GPIO0:** Энкодер (`CLK`, `DT` с подтяжкой к `GND`, кнопка `SW` с подтяжкой к `+3.3 В`, общий `C` на `+3.3 В`).
* **ADC (A0):** Контроль АКБ 18650 через делитель `330 кОм / 100 кОм`.
* **PCF8574:** `P0–P3` — реле, `P4–P6` — резерв, `P7` — контроль входных 24 В (через делитель `10 кОм / 15 кОм` с первичной шины 5 В).

## Первый запуск

1. Точка доступа по умолчанию: **`Meteo_ESP07`**, пароль **`12345678`**, адрес **`http://192.168.4.1`**.
2. Логин / пароль для настроек в Web: **`admin`** / **`admin`**.
3. После включения выполните сканирование шин `1-Wire` и `I2C` через локальное меню энкодером.
